# Automation Services Website

Static business website with a custom Python build and quality-assurance pipeline.

## Engineering highlights
Source content is processed by build tools that generate navigation, metadata, structured data, sitemaps and optimized image markup.

Automated checks cover SEO metadata, local links, structured data, social metadata, asset budgets, WCAG contrast, print/PDF output, runtime browser errors, CSP compatibility and mobile interaction regressions.
